# 🚚 Fleet Performance & Delivery Efficiency Dashboard

## 📌 Project Overview
This project focuses on analyzing fleet operations and delivery efficiency using Microsoft Power BI. The dashboard provides insights into delivery performance, fuel efficiency, transportation costs, and vehicle maintenance to help identify operational trends and improve fleet management.

## 🎯 Project Objectives
- Analyze on-time delivery performance.
- Track fuel efficiency trends.
- Evaluate average transportation cost per kilometer.
- Compare delivery performance across destinations.
- Analyze vehicle types and maintenance costs.
- Identify factors influencing delivery status.

## 📊 Dashboard Insights
- **On-Time Delivery:** Monitor overall delivery performance.
- **Delivery by Destination:** Compare delivery efficiency across destinations.
- **Fuel Efficiency Trend:** Track fuel efficiency over time.
- **Cost per KM Categories:** Analyze transportation cost categories.
- **Delivery Status:** Identify key factors influencing delivery status.
- **Vehicle Maintenance:** Compare vehicle types based on maintenance costs.

## 📈 Key Skills Demonstrated

## 💡 Business Benefits
This dashboard helps fleet managers monitor operational efficiency, identify delivery delays, control transportation costs, evaluate fuel performance, and make informed decisions regarding vehicle maintenance.
